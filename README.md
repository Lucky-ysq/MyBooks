# MyBooks — 遇夏小说

个人使用的安卓小说阅读软件（参考番茄小说与「阅读」类阅读器交互）。

- **前端**：uniapp（Vue3 语法，HBuilderX 工程），仅安卓端，打包 APK
- **后端**：Spring Boot + MyBatis-Plus + SQLite + Jsoup，部署在阿里云服务器
- **数据**：书架、阅读进度、下载章节、设置全部存手机本地；服务器只存书源规则
- 书源（小说网站网址）在 App「我的 → 书源管理」里填写，支持内置模板一键配置

> 声明：小说软件壳，无书源配置，使用AI制作。学习软件，个人使用，无商业行为。

## 功能一览

| 模块 | 说明 |
|---|---|
| 书架 | 图书列表（封面/作者/进度/最新章节），已下载标识，点击继续阅读 |
| 搜索 | 选书源搜书名/作者，一键加入书架 |
| 阅读器 | 目录/界面设置/设置三键工具栏，字号/行距/背景色/翻页方式，进度自动保存 |
| 目录 | 章节列表正序/倒序，批量下载（全本/最近50章/自定义范围） |
| 离线下载 | 章节存本地断网可读，下载管理页查看进度/删除/清空 |
| 我的 | 书源管理、阅读偏好、下载管理、备份与恢复、关于 |

## 快速开始（开发调试）

1. **后端**：`cd backend && mvn spring-boot:run`（默认 8080 端口），接口自测见 docs/04
2. **前端**：用 HBuilderX 打开 `app/` 目录 → 运行 → 运行到浏览器或安卓真机
3. App 首次启动在「我的 → 关于 → 服务器地址」填后端地址（调试填局域网 IP）
