# 03 开发环境搭建

## 1. 需要安装的东西

| 工具 | 用途 | 说明 |
|---|---|---|
| JDK 8+ | 跑后端 | 本机已装 JDK 21 可直接用；服务器推荐 OpenJDK 17 |
| Maven 3.8+ | 构建后端 | 本机已装 3.10 可直接用 |
| HBuilderX（标准版） | 前端开发 + 打包 APK | 官网 https://www.dcloud.io/hbuilderx.html 免费 |
| Git | 版本管理 | 已装 |

> HBuilderX 是 DCloud 官方免费 IDE，uniapp 项目必须用它来「运行预览」和「云打包 APK」。安装后第一次使用需注册免费 DCloud 账号（打包时登录用）。

## 2. 后端运行（开发）

```bash
cd backend
mvn spring-boot:run
# 启动后 http://127.0.0.1:8080/api/health 返回 {"code":0,...} 即成功
```

首次启动自动：创建 `backend/data/mybooks.db`（SQLite）→ 建表 → 插入内置本地测试源。

打包：

```bash
cd backend
mvn clean package -DskipTests
# 产物：backend/target/books-*.jar
java -jar target/books-1.0.0.jar   # 服务器上这样跑
```

## 3. 前端运行（开发预览）

1. 打开 HBuilderX → 文件 → 导入 → 从本地目录导入 → 选 `app/` 文件夹
2. 菜单 运行 → **运行到浏览器**（Chrome）：最快预览 UI
3. 或 运行 → **运行到手机或模拟器**（安卓手机开 USB 调试连电脑）：最接近真实体验
4. 预览时后端地址：浏览器预览用 `http://127.0.0.1:8080`；真机预览用电脑局域网 IP（cmd `ipconfig` 查 IPv4，如 `http://192.168.1.5:8080`），在 App「我的 → 关于 → 服务器地址」里填写

> 注意：浏览器预览时部分 App 专有 API（屏幕常亮等）不生效属正常，真机/打包后正常。

## 4. 常用自测命令（后端）

```bash
curl http://127.0.0.1:8080/api/health
curl "http://127.0.0.1:8080/api/sources"
curl "http://127.0.0.1:8080/api/search?sourceId=1&keyword=斗破苍穹"
curl "http://127.0.0.1:8080/api/book/chapters?sourceId=1&bookUrl=..."
curl "http://127.0.0.1:8080/api/book/content?sourceId=1&chapterUrl=..."
```

## 5. 开发注意事项（写给后续接手的人/Agent）

- 语法保持基础：Java 8 语法、Vue3 选项式或组合式但不玩花活、不引额外框架
- 每完成一个里程碑：更新 `docs/04-开发进度交接.md` 再收尾
- 后端改接口必须同步更新 02 文档的 API 表
- 前端页面文件都在 `app/pages/`，新增页面记得登记 `app/pages.json`
- 不要提交 `app/unpackage/`（HBuilderX 编译产物）和 `backend/target/`（已在 .gitignore）
