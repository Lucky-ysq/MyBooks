## 0. 项目一句话

遇夏小说：uniapp(Vue3) 安卓 App + Spring Boot 后端的书源小说阅读器，用户数据全在手机本地，服务器只存书源规则。仓库：https://gitee.com/luckyThings/MyBooks.git

**已知问题/注意：**
- 本机访问 GitHub 超时，但 Gitee 正常，push 走 Gitee
- 若真实镜像站抓不通（网络波动），先用本地测试源联调，不阻塞
- 阿里云服务器、域名、DCloud 账号：用户 M6 阶段提供/操作
- **本机 shell 的 PATH 会被重置成 Windows 格式**，每条命令前需加：`export PATH="/usr/bin:/mingw64/bin:/f/maven/apache-maven-3.10.0/bin:/f/java/bin:/f/nodejs:/f/Git/cmd:/c/Windows/System32:/c/Windows"`
- Git Bash 终端直接 curl -d 发中文会变 GBK 乱码（终端编码问题，非服务端 bug）；测试时中文 body 用 `--data-binary @文件`（UTF-8）

### 会话 2（2026-10-14）
**已完成（M1 后端全部）：**
- backend Maven 工程：Spring Boot 2.7.18 + MyBatis-Plus 3.5.3.2 + sqlite-jdbc 3.44 + Jsoup 1.17.2 + Lombok，Java 8 语法
- 包结构：controller(Source/Book/Misc) + service(Source/Book + MockBookData) + entity(BookSource/SourceRules) + util(JsoupFetcher/RuleParser) + common(Result/异常处理/模板) + config(CORS/DataInit)
- 书源 CRUD + 设默认 + 测试接口；规则不填自动套笔趣阁模板；至少保留一个书源
- 内置「本地测试源」（mock://local，3 本假书各 30 章）启动自动插入；真实源走 Jsoup 按 rules JSON 解析（搜索支持 GET/POST、{{key}} 占位、gbk 编码、相对地址补全、多选择器逗号回退）
- 正文解析：<br>/<p> 转换行、去广告元素、实体解码、按段落返回
- 图片代理 /api/image（Referer 用目标站首页绕防盗链）

**自测结果（全部通过，服务跑在 127.0.0.1:8080）：**
| 接口 | 结果 |
|---|---|
| GET /api/health | code=0 ✓ |
| GET /api/sources | 2 条内置源 ✓ |
| POST/PUT/DELETE /api/sources、POST .../default | code=0 ✓（删后恢复 2 条）|
| GET /api/search（本地测试源）| 3 条结果 ✓ |
| GET /api/book/detail、/chapters、/content | 数据正确 ✓ |
| GET /api/sources/{id}/test | ✓ |
| GET /api/image?url=非法 | 正确报错 ✓ |

构建：`cd backend && mvn clean package -DskipTests` → `target/books-1.0.0.jar`（约 30 秒）。
遇过的坑：Jsoup Entities 在 org.jsoup.nodes 包（不是 parser）；已修。
