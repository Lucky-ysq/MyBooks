# 01 项目需求文档（PRD）

软件名：**遇夏小说**  
定位：个人使用的安卓小说阅读 App（壳），书源由使用者自行填写。  
参考：番茄小说 + 用户提供的 7 张「阅读」类阅读器截图。

---

## 1. 总体要求

| 项 | 要求 |
|---|---|
| 使用端 | 仅安卓（uniapp 打包 APK） |
| 页面 | 底部 2 个 Tab：**书架、我的** |
| 阅读页工具栏 | 只放 3 个键：**目录、界面设置、设置** |
| 数据 | 书架/进度/下载/设置存**手机本地**；服务器只存书源规则 |
| 书源 | 小说网站网址（HTML），App 内「书源管理」填写 |
| 语法 | 尽量基础，能用现成框架就用（见 02 文档技术栈） |

## 2. 页面明细

### 2.1 书架页（首页，Tab1）
- 顶部：App 名「遇夏小说」+ 搜索入口（胶囊形搜索框，点击进搜索页）
- 列表：单列图书项（封面缩略、书名、作者、阅读进度文案如「已读 45%·第 120 章」、最新章节名）
- 整本已下载的书显示「已下载」角标
- 点击图书 → 进阅读页（接着上次进度）
- 长按图书 → 删除出书架（确认弹窗，可同时删除本地缓存）
- 空状态：引导去搜索页添加图书
- 按最近阅读时间排序

### 2.2 搜索页（从书架进入，非 Tab）
- 顶部搜索框 + 当前书源（下拉可切换，来自书源管理里启用的源）
- 输入书名/作者 → 调后端搜索 → 结果列表（封面、书名、作者、简介摘要）
- 结果点击 → 弹出书籍详情（封面/书名/作者/简介）+「加入书架」「立即阅读」按钮
- 已在书架的书显示「已在书架」

### 2.3 阅读页（核心）
- 顶部栏（点击屏幕中央呼出）：返回、书名、章节名
- 正文区：章节标题 + 段落文字；支持上下滚动 / 左右滑动两种翻页方式
- 点击屏幕**中央区域**呼出工具栏；点击两侧翻页（左右滑动模式下）
- 底部工具栏（呼出时显示）：
  - **目录** → 打开目录页
  - **界面设置** → 弹出阅读界面设置面板
  - **设置** → 弹出阅读设置面板
  - 底部附：上一章 / 下一章 按钮
- **界面设置面板**（参考截图）：
  - 字号（A- / A+，范围 12~36）
  - 行距（1.2~2.4 倍）
  - 背景色：白 / 米黄 / 护眼绿 / 深灰 / 黑（含夜间黑）
  - 翻页方式：上下滚动 / 左右滑动
  - 设置即存即生效（全局阅读偏好）
- **设置面板**：
  - 夜间模式开关（跟随背景色联动）
  - 屏幕常亮开关（阅读时不锁屏）
  - 后端服务器地址（调试用，改后立即生效）
- 章节加载：优先读本地缓存/下载，无缓存走网络；加载中显示提示，失败可重试
- 进度自动保存：书籍 id、当前章节号、滚动位置；退出再进自动恢复
- 章末自动预取下一章

### 2.4 目录页（从阅读页进入）
- 顶部：书名 + 总章数（如「共 1523 章」）
- 章节列表（序号+章节名），当前阅读章高亮
- 正序/倒序切换按钮
- **批量下载**入口：
  - 可选范围：全本 / 最近 50 章 / 自定义起止章
  - 下载中显示进度（已下/总数），可暂停、继续
  - 已下载章节在列表中显示标识
- 点击章节 → 跳转阅读该章

### 2.5 我的页（Tab2）
- 顶部：头像（本地默认图）+ 名称「遇夏读者」+ 简单一句话
- 菜单列表（图标 + 名称 + 箭头）：
  1. **书源管理** → 书源管理页
  2. **阅读偏好** → 全局默认阅读设置（字号/行距/背景/翻页方式/夜间模式）
  3. **下载管理** → 下载管理页
  4. **备份与恢复** → 导出/导入书架与进度（JSON 文件）
  5. **关于遇夏小说** → 版本、服务器地址配置、开源地址
- 风格：白底、红色系强调色（参考截图）

### 2.6 书源管理页
- 书源列表：名称、网址、启用开关；默认源标记（搜索页默认用）
- 添加书源：
  - **简单模式**：只需填 名称 + 站点网址，选「笔趣阁通用模板」一键带出规则
  - **高级模式**（可折叠）：可编辑各解析规则（搜索地址模板、编码、选择器等，字段见 02 文档）
- 编辑/删除书源；点击「测试」按钮验证书源可用（搜一个关键字返回结果即成功）
- 至少保留一个启用书源；后端启动时若库为空自动写入一个内置测试源

### 2.7 下载管理页
- 每本有下载的书一行：封面、书名、已下载 x 章/共 y 章、进度条
- 操作：继续下载（补未下章节）、删除本书缓存、全部暂停
- 顶部：一键清空所有缓存 + 总占用空间显示

### 2.8 备份与恢复
- 导出：把书架 + 阅读进度 + 设置导出为 JSON 文件（App 端保存到下载目录并提示路径）
- 导入：选择 JSON 文件恢复（合并策略：以导入为准覆盖同书进度）
- 说明：章节缓存不参与备份（体积大，可重新下载）

## 3. 非功能需求

- 断网：已下载/已缓存章节可正常阅读；书架/进度/设置全部可用
- 后端不可达：明确的错误提示（含服务器地址检查指引）
- 性能：单章正文 < 100KB；书架 100 本内流畅
- 兼容：安卓 8.0+；后端 JDK 8+ 可跑

## 4. 明确不做（本期）

- 朗读 TTS、自动翻页、仿真翻页动画
- 换源（同一本书切换不同书源）
- 多端同步、账号系统
- iOS / H5 适配（H5 仅作为 HBuilderX 调试预览）
